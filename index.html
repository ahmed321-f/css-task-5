Understanding Width, Height, Padding and Border

1. Introduction

The CSS Box Model is an important concept in CSS. Every HTML element is displayed as a rectangular box. It consists of Content, Padding, Border and Margin.

2. CSS Box Model - Width

4. Four Parts of CSS Box Model

1. Content

The actual text or image inside an HTML element.

2. Padding

The space between content and border.

3. Border

The line surrounding the content and padding.

4. Margin

The space outside the border.
